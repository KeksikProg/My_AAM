# AAM
AAM - Метод, сочетающий форму и текстуру объекта для его анализа и синтеза.
Мы создаем статистические модели внешнего вида, комбинируя модели изменения формы и модели изменения текстур.

Под "текстурой" подразумевается распределение интенсивности(яркость пикселя) или цвета по фрагменту изображения. 

### Основные этапы AAM
1. Подготовка данных. 
	 Данные хранятся в формате очень похожем на датасет Yolo. Данные разделены на:
	 - Папка с самими фотографиями
	 - Папка с разметкой(Landmarks). Обычно просто последовательность координат X, Y для каждой из точек, по крайней мере как я понял 

2. Построение модели формы (Shape Model)
	- Выравнивание форм, приведение к чему-то общему через устранение различий в повороте, масштабе, и смещении через **Анализ Прокруста** (Rigid Aligment\Жесткое выравнивание\Аффинные преобразования)
	- Использование **PCA (Метод главных компонент)** на размеченных точках для выявления основных вариаций формы. 

3. Построение модели текстуры (Texture Model)
	- Нормализация текстур:
	    - Деформация текстур к **средней форме** (warping с треугольной интерполяцией).
	    - Коррекция освещения **(z-score)**
	
	- Использование **PCA (Метод главных компонент)** к текстурным моделям, опять же для выделения основных вариаций текстуры.
4. Комбинированная модель (Combined Appearance Model)
	- Параметры формы и параметры текстур объединяются в один вектор, и опять применяется **PCA** для устранения **избыточности и размерности** между параметрами

5. Итеративное "уточнение" модели (Itrative Model Refinement)
	- Используя матрицу R мы можем вносить коррективы в параметры модели на основе измеренного остатка. Это позволяет построить итеративный алгоритм для решение задачи оптимизации. Мы учитываем текущие параметры:
	    - c - комбинированные параметры текстуры и формы 
	    - u - параметры формы(определяет контур). описывает локальные изменения
	    - t - текстурные параметры (заполняет контур цветом). Описывает локальные изменения.
	    - gim - глобальные изменения
	
	
    - Итеративное уточнение
	1. Проекция текстуры текущего изображения в модель текстуры(gs = T_u^-1 (g_im))
	    Мы берем текстуру из изображения на данной итерации, приводим её к виду, который соответствует эталонной текстуре модели(нормализация текстур) для того, чтобы убрать лишние блики, отсветы и тд.
	    T_u^-1 - Обратное преобразование текстуры(нормализация яркости\контраста и обратное деформирование warping. Как Анализ Прокруста для формы, только для текстуры.)
	2. Вычисляем остатки (r = gs -gm) и ошибку (E = lrl^2)
	    r - разница между спроецированной текстурой (gs) и текстурой модели (gm)
	    E - квадрат длины вектора остатков (чем меньше, тем соответственно лучше)
	    Показывает то, насколько модель не соответствует изображению
	3. Предсказание коррекции параметров (Δp = -R * r(p))
	    Умножаем остаток r на матрицу R с минусом (заранее вычислили через Якобиан)
	    Δp - предложение как стоит изменить параметры, чтобы уменьшить остатки (получить лучшую версию)
	    Минус по аналогии с градиентным спуском, без него матрица R будет показывать в направление увеличения остатков, т.е. ухудшения модели
	4. Обновление параметров (p = p + k * Δp)
	    Все просто, пробуем обновить параметры с коэффициентом k = 1 для начала
	5. По обновленным параметрам пересчитываем форму (X') и текстуру модели (gm')
	6. Берем пиксели(интенсивность или цвет) из обновленных положений точек формы (g_im')
	7. считаем новые остатки r' = T_u'^-1 (g_im') - gm'
	8. Если длина квадратов обновленных остатков (lr'l^2) меньше, чем прошлая ошибка E, то обновления параметров применяются и процесс идет сначала, если нет, то новые параметры не применяются, коэффициент k делится на 2 и процесс идет сначала, пока остатки не станут меньше. 

### Моя реализация AAM
На данный момент времени было решено, что ААМ не будет иметь метода понижений размерности PCA, не будет иметь нормализации освещения, с помощью z-score, и нормализация формы будет производится с помощью метода Кабша. 
Реализована оптимизация как параметров формы, так и параметров внешности. Также для более качественной работы были использованы пирамиды изображений при оптимизации на новых изображениях
